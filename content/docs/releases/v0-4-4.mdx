Released 2026-10-14. v0.4.4 is a beta-fixes release on top of the [v0.4.3](/docs/releases/v0-4-3) security patch. One migration (the schema moves from version 44 to 45).

## Highlights

- **"Working on it…" while an answer waits.** When a request queues behind the model connection's requests-per-minute limit, or a SystemOne request queues for a busy slot, for about a second or more, the chat shows "Working on it…" (and says it once to screen readers) instead of a status that stands still. The step the reader was on comes back when the wait ends, and nothing is shown once the model starts writing. The API's `status` event has a new step, `waiting`; clients already ignore steps they don't know.
- **Models that ignore "How to turn thinking off" are found and handled.** Some reasoning models keep thinking whatever switch is sent. The model **Test** in Admin → Models now makes a second request the way an agent's Reasoning effort **Off** does, and says whether the model still reasoned. The result is kept on the model and shown on its page (**Thinking off: Works** or **Ignored**, with the date), and **Build → Advanced → Reasoning effort** labels **Off (ignored by this model)** and warns once it is chosen. It is deliberately not a health status: a model that thinks too much is not counted as failing. A [follow-up suggestion](/docs/using/follow-up-suggestions) call that runs out of tokens thinking is retried once with a larger budget, so the chips still appear. The trace carries `gen_ai.usage.reasoning_tokens`.
- **A Profile page, and your API keys in the account menu.** **Profile** (`/settings/profile`) shows who you are, when you joined and last signed in, and your teams with your role. **API keys** (`/settings/api-keys`) lists your personal keys in every team, each linking to its page in the team's settings, with a link to create one there. Both are in the account menu and the command palette. See [Your settings](/docs/using/personal-settings).
- **The OCR image is on Debian 13.** Tesseract is 5.5.0 instead of 5.3.0, and the image scan finds 327 unfixed Debian findings instead of 415 (1 critical instead of 3, 76 high instead of 88; none has a fix available in either). On six synthetic pages the two engines read identically.
- **Dependencies are current:** 24 Go modules (including River 0.47 to 0.49, OpenTelemetry 1.47 and the AWS SDK), the web group's minor and patch updates, and the GitHub Actions used by CI.

## Requirements

Unchanged from [v0.2.0](/docs/releases/v0-2-0#requirements).

## Upgrading from v0.4.3

A rolling upgrade with no downtime. Take a backup as for any upgrade, then change every `?ref=v0.4.3` in your overlay to `?ref=v0.4.4` and pin the new digests of `ghcr.io/ncecere/grounded` and, if you run OCR, `ghcr.io/ncecere/grounded-ocr`. See [Upgrades](/docs/self-hosting/upgrades).

- **One migration** (the schema moves from version 44 to 45): two nullable columns on `models` for the result of the thinking-off check. Nothing is rewritten and nothing needs configuring.
- **River's own schema moves to version 8**, which River applies at startup. Its migration 008 is a no-op on PostgreSQL.
- **No new environment variables**, and nothing changed in `deploy/kubernetes` or `deploy/observability`.
- **If you derive from the OCR image** (`FROM ghcr.io/ncecere/grounded-ocr`, usually to add languages), its base is now Debian 13: check the `apt-get install` of any extra `tesseract-ocr-*` package against Debian 13's names, and re-check OCR output on a few of your own scans, since Tesseract is a newer engine.

## API changes

All additive. `Model` and the chat model options gain `thinkingOffCheck`, `ModelTestResult` gains `thinkingOff`, and `status` chat events can carry the step `waiting`. The [API reference](/docs/api) describes them.

## Known limitations

The [v0.4.2 limitations](/docs/releases/v0-4-2#known-limitations) still apply, and:

- The thinking-off result is kept until the model's compatibility settings or upstream model change. Changing the **connection** (its address or key) does not clear it; the date is shown beside it, and testing again refreshes it.
- "Working on it…" covers the connection's request limit and SystemOne's slots. A gateway that is slow on its own side shows the "thinking" step, as before.
- The OCR image still carries unfixed Debian findings; whether any is reachable from the OCR service has not been assessed.
- The Profile page is read-only: your name and email come from how you sign in.

## Verifying the images

As for [v0.2.0](/docs/releases/v0-2-0#verifying-the-images), with the tag `v0.4.4`: `docker run --rm ghcr.io/ncecere/grounded@sha256:<digest> version` prints `grounded v0.4.4 (<commit>)`.
