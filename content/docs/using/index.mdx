What you can do in a team depends on your role. Everyone can chat with the agents shared with them. Editors build data sources, knowledge bases, agents and evaluations. Owners and admins also manage members, API keys and the team's spend. [Concepts](/docs/getting-started/concepts#roles) has the full table.
